# Synthetic example reports

Open `demo_report.html` for the stock-universe software demonstration, or `etf_demo_report.html` for the ETF-universe demonstration. Both contain risk forecast scores, paired bootstrap intervals, and all six robustness cases. Every performance number is generated, not historical market evidence.

`signal_demo_report.html` shows the same synthetic software validation for the WorldQuant-style rank signal. Its large turnover and negative neutral performance are not historical market results.
